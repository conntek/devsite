# KTH16xx系列 - 霍尔开关传感器

## 系列概述

KTH16xx系列是昆泰芯微电子推出的高性能霍尔开关传感器系列，涵盖了单极、双极、全极等多种检测类型，具有超低功耗、高灵敏度、宽工作电压范围等特点，广泛应用于消费电子、工业控制、汽车电子等领域。

## 核心特性

- **超低功耗设计**：工作电流低至1.5μA
- **宽工作电压**：支持1.65V-5.5V工作电压
- **高磁场灵敏度**：多种磁场阈值选择
- **丰富封装选择**：SOT-23、TO-92S等多种封装
- **工业级可靠性**：-40°C至+85°C工作温度范围
