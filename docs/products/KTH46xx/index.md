# KTH46xx系列 - 3D霍尔传感器

## 系列概述

KTH46xx系列是昆泰芯微电子推出的高性能3D霍尔传感器系列，专为高精度磁场检测应用设计，具有优异的线性度和温度稳定性。

## 产品列表

### 3D霍尔传感器
- [KTH462N](./KTH462N.md) - 3D霍尔传感器
- [KTH462NXX](./KTH462NXX.md) - 3D霍尔传感器系列

## 核心特性

- **三轴检测**：X、Y、Z轴磁场同时检测
- **高线性度**：优秀的磁场线性响应
- **低噪声**：高信噪比设计
- **宽动态范围**：大磁场检测范围
- **数字接口**：标准I2C/SPI通信
- **温度补偿**：内置温度校正

## 应用领域

- 精密磁场测量
- 位置和角度检测
- 电流检测应用
- 磁性材料检测
- 科学研究仪器
- 工业检测设备

## 技术优势

- **高精度**：优化的传感器设计
- **稳定性**：长期稳定的输出特性
- **抗干扰**：强EMC性能
- **易集成**：标准数字接口
