# KTM13xx系列 - 磁编码器

## 系列概述

KTM13xx系列是昆泰芯微电子推出的高性能磁编码器系列，专为工业级应用设计，具有高可靠性、强抗干扰能力和优秀的环境适应性。

## 核心特性

- **工业级设计**：适用于恶劣工业环境
- **高分辨率**：多种分辨率选择
- **强抗干扰**：优秀的EMC性能
- **宽温度范围**：-40°C至+125°C
- **长期稳定**：优异的长期漂移特性
- **多接口支持**：SPI、I2C、模拟输出
- **低功耗设计**：适合连续工作
