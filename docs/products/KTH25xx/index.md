# KTH25xx系列 - 霍尔开关传感器

## 系列概述

KTH25xx系列是昆泰芯微电子推出的高性能霍尔开关传感器系列，专注于高精度磁场检测应用，具有优异的温度稳定性和长期可靠性。

## 产品列表

### 高精度霍尔开关
- [KTH2502](./KTH2502.md) - 高精度霍尔开关传感器
- [KTH2582](./KTH2582.md) - 高精度霍尔开关传感器

## 核心特性

- **高精度检测**：精确的磁场阈值控制
- **温度补偿**：优秀的温度稳定性
- **低噪声设计**：高信噪比输出
- **快速响应**：微秒级响应时间
- **长期稳定**：优异的长期漂移特性
