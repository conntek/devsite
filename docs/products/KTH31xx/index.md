# KTH31xx系列 - 3D霍尔传感器

## 系列概述

KTH31xx系列是昆泰芯微电子推出的高性能3D霍尔传感器系列，能够同时检测X、Y、Z三个轴向的磁场强度，为复杂的磁场检测应用提供完整解决方案。

## 产品列表

### 3D霍尔传感器
- [KTH31XX](./KTH31XX.md) - 3D霍尔传感器系列

## 核心特性

- **三轴检测**：同时检测X、Y、Z轴磁场
- **高分辨率**：优秀的磁场分辨率
- **数字输出**：I2C/SPI数字接口
- **温度补偿**：内置温度传感器
- **低功耗设计**：适合电池供电应用
- **小型封装**：紧凑的QFN封装

## 应用领域

- 电子罗盘导航
- 姿态检测系统
- 3D位置感知
- 磁场映射
- 虚拟现实设备
- 游戏控制器
- 工业自动化

## 技术优势

- **多轴同步**：三轴磁场同步采样
- **高精度校准**：工厂预校准
- **灵活配置**：可编程采样率和滤波
- **抗干扰**：优秀的EMC性能
