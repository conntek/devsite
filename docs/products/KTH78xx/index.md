# KTH78xx系列 - 磁编码器

## 系列概述

KTH78xx系列是昆泰芯微电子推出的高性能磁编码器系列，专为精密角度和位置检测应用设计，具有高分辨率、高精度、快速响应等特点。

## 核心特性

- **高分辨率**：最高14位角度分辨率
- **高精度**：优秀的角度精度
- **快速响应**：高速采样率
- **数字输出**：SPI/I2C数字接口
- **360°检测**：全角度范围检测
- **温度补偿**：内置温度校正
- **低功耗**：适合电池供电

## 技术规格

### 分辨率等级
- **12位**：4096个位置点
- **13位**：8192个位置点
- **14位**：16384个位置点

### 精度等级
- **标准精度**：±0.5°
- **高精度**：±0.25°
- **超高精度**：±0.1°

- **非接触检测**：无磨损、长寿命

- **易安装**：简单的机械安装
- **成本效益**：替代光学编码器
