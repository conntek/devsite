# 产品中心

## 产品概览

昆泰芯微电子专注于磁传感器技术的研发和产业化，为客户提供全系列的磁传感器解决方案。我们的产品涵盖霍尔开关、3D霍尔传感器、磁编码器等多个系列，广泛应用于消费电子、工业自动化、汽车电子等领域。
