# KTH15xx系列 - 超低功耗霍尔开关综述

[返回霍尔开关目录](../index.md)

## 系列概述

**KTH15xx系列**是专为电池供电应用设计的超低功耗霍尔开关系列，采用先进的微功耗技术，实现了业界领先的低功耗性能。该系列产品具有高磁场灵敏度、全极性检测和宽工作电压范围，特别适合物联网、便携设备和长期无人值守的应用场景。

---

## 🔋 系列核心特性

### ⚡ 超低功耗设计
- **微安级功耗**：1.6μA@1.8V典型功耗
- **电池友好**：延长电池使用寿命
- **多频率选择**：5Hz/20Hz采样频率可选
- **宽电压范围**：1.6V-5.5V工作电压

### 🎯 高灵敏度检测
- **全极性检测**：南北极均可触发
- **多灵敏度等级**：±22Gs/±33Gs/±46Gs可选
- **温度补偿**：全温度范围稳定工作
- **高ESD等级**：HBM 8KV保护

### 📦 灵活封装选择
- **表贴封装**：SOT-23-3L (MSL1)
- **插装封装**：TO-92S
- **工业级温度**：-40°C~+125°C
- **RoHS兼容**：环保材料

### 🔌 简化设计
- **推挽输出**：无需外部上拉电阻
- **CMOS输出**：直接驱动数字电路
- **单电源供电**：简化电源设计
- **噪声免疫**：优异的抗干扰能力

## 🔧 工作原理

### 霍尔效应检测
- **全极性检测**：南极或北极磁场均可触发
- **磁滞特性**：避免输出抖动，提高稳定性
- **温度补偿**：内置温度补偿电路
- **低功耗采样**：间歇性检测降低功耗

### 输出特性
- **推挽输出**：CMOS推挽结构
- **逻辑电平**：磁场存在时输出低电平
- **驱动能力**：1mA输出电流
- **无需上拉**：内置输出驱动

## 🛠️ 应用指南

### 基本应用电路
```
VDD ----+---- VDD (Pin 1)
        |
        C (1μF) // 去耦电容
        |
GND ----+---- GND (Pin 2)

OUT --------- OUT (Pin 3) ---- 输出
```

### 设计要点
1. **去耦电容**：VDD端添加1μF去耦电容
2. **电容位置**：尽量靠近电源引脚
3. **PCB布局**：避免大电流走线干扰
4. **磁场方向**：垂直于芯片表面

### 磁铁配置
- **磁铁类型**：永磁铁（钕铁硼推荐）
- **磁场强度**：>30Gs（在传感器位置）
- **安装距离**：1-10mm
- **磁极方向**：南极或北极均可
