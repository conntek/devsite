# KTH13xx系列 - 1D X轴霍尔开关综述

[返回霍尔开关目录](../index.md)

## 系列概述

**KTH13xx系列**是昆泰芯微电子推出的1D X轴霍尔开关传感器系列，专为单轴磁场检测应用设计。该系列采用先进的霍尔效应技术，能够精确检测X轴方向的磁场变化，具有高灵敏度、快速响应、抗干扰能力强等特点。

## 系列特性

### 🎯 单轴精密检测
- **X轴专用**：专门检测X轴方向磁场，抗干扰能力强
- **高灵敏度**：低磁场强度触发，适合弱磁场应用
- **精确定位**：单轴检测提供精确的位置信息
- **抗干扰**：对其他轴向磁场干扰免疫

### ⚡ 快速响应特性
- **微秒级响应**：上升/下降时间典型值0.5μs
- **高开关频率**：最高100kHz开关频率
- **低延迟**：适合高速检测应用
- **稳定输出**：磁滞特性避免输出抖动

### 🔋 优化功耗设计
- **低功耗**：典型工作电流3.5mA
- **宽电压范围**：2.5V~18V工作电压
- **电池友好**：适合电池供电应用
- **节能设计**：优化的电路架构

### 🌡️ 宽温度范围
- **工作温度**：-40℃~+150℃
- **存储温度**：-65℃~+170℃
- **温度补偿**：内置温度补偿电路
- **温度稳定性**：全温度范围稳定工作

### 📦 紧凑封装
- **SOT-23-3封装**：2.9×1.3×1.0mm小型化设计
- **表贴安装**：适合自动化生产
- **标准引脚**：兼容标准PCB设计
- **节省空间**：适合空间受限应用

## 工作原理

### X轴检测原理
- **单轴检测**：专门检测X轴（垂直于芯片表面）方向磁场
- **霍尔效应**：基于霍尔效应检测磁场变化
- **开关动作**：当X轴磁场强度超过工作点时输出低电平
- **磁滞特性**：具有磁滞特性，避免输出抖动
- **温度补偿**：内置温度补偿电路，保证温度稳定性

### 输出特性
- **输出类型**：开漏输出
- **逻辑电平**：磁场存在时输出低电平，磁场消失时输出高阻
- **驱动能力**：可驱动LED、继电器等负载
- **上拉电阻**：需要外接上拉电阻

## 应用指南

### 🎯 产品选型建议

#### 按应用精度选择
- **标准应用**：选择KTH1361
- **高精度要求**：选择KTH1362
- **位置检测**：根据精度要求选择
- **接近开关**：标准型号即可满足

#### 按电源系统选择
- **低压系统**：2.5V~5V应用
- **标准系统**：5V~12V应用
- **高压系统**：12V~18V应用
- **电池供电**：考虑低功耗特性

### 🔧 典型应用电路

#### 基本检测电路
```
VDD ----+---- VDD (Pin 1)
        |
        R (上拉电阻 10kΩ)
        |
        +---- OUT (Pin 3) ---- 输出
        
GND --------- GND (Pin 2)
```

#### LED指示电路
```
VDD ----+---- VDD (Pin 1)
        |
        R1 (10kΩ)
        |
        +---- OUT (Pin 3) ----+---- 输出
                              |
                              R2 (330Ω)
                              |
                              LED
                              |
GND --------- GND (Pin 2) ----+
```

#### 位置检测电路
```
VDD ----+---- VDD (Pin 1)
        |
        R1 (10kΩ)
        |
        +---- OUT (Pin 3) ---- MCU输入
        
GND --------- GND (Pin 2)

磁铁（X轴方向移动）
  ↓
传感器
```

### 📊 设计要点

#### 电路设计
- **上拉电阻**：输出端需要上拉电阻，推荐10kΩ
- **电源去耦**：VDD端添加0.1μF去耦电容
- **负载驱动**：大电流负载需要驱动电路
- **EMI抑制**：添加适当的滤波电路

#### PCB布局
- **传感器位置**：靠近磁场源放置
- **接地设计**：保持良好的接地
- **信号完整性**：最小化寄生电容
- **热设计**：考虑散热要求

#### X轴磁场设计
- **磁铁选择**：推荐使用永磁铁（NdFeB）
- **磁场强度**：在传感器位置>5mT
- **检测距离**：0-10mm检测距离
- **磁场方向**：X轴（垂直于芯片表面）
- **磁场均匀性**：在检测区域内磁场应均匀
