## 关于昆泰芯微电子

昆泰芯微电子是一家专注于智能传感器芯片研发、生产及销售的高新技术企业。以 "智能感知世界，传递美好生活" 为使命，聚焦智能运动位置感知芯片传感解决方案。

公司主要提供**高性能、低功耗传感器芯片产品**，以磁性传感器芯片为龙头，产品线包括：
- 磁性传感器芯片
- 高性能传感信号调理芯片  
- 光学传感器芯片
- 温度传感器芯片

其中**3D霍尔芯片**、**高精度低延时角度TMR编码器芯片**、**近零功耗磁性开关**、**超高速磁性电流传感器ASIC**均达到**世界领先水平**。

### 技术与团队

- 公司具备国内最完备的磁传感器技术开发能力，包括：**3D霍尔、AMR、TMR、磁通门**等多种技术方案
- 核心团队毕业于清华大学、北京大学、荷兰代尔夫特理工大学、瑞士洛桑理工学院等国内外知名高校
- 团队曾就职于恩智浦、美满电子、高通、MPS、IBM等知名半导体企业
- 已获得**超过100项核心专利**

### 应用领域

产品广泛应用于：
- 机器人与自动化
- 智能人机交互
- 新能源及智能汽车等领域

### 服务内容

- **磁敏元件和ASIC芯片定制**
- **磁路设计 / 磁铁选型 / 电磁仿真 / 电磁屏蔽设计**
- **PCBA电路 / 传感器模组结构设计**
- **算法软件支持**
