# PDF转Markdown图片质量优化解决方案

## 问题描述

在PDF转换过程中，提取的图片存在以下问题：
- 部分图片完全是黑色的
- 一些图片质量很差，内容单一
- 包含大量装饰性小图片

## 解决方案

### 1. 基础版本 (`pdf_to_md_with_images.py`)
- 基本的图片提取功能
- 简单的尺寸过滤（过滤小于50x50的图片）
- CMYK到RGB颜色空间转换

### 2. 图片质量分析工具 (`clean_images.py`)
- 使用PIL和NumPy进行深度图片分析
- 多维度质量检测：
  - 亮度分析（平均值、标准差、范围）
  - 黑色像素比例检测
  - 颜色多样性分析
  - 图片内容统一性检查

### 3. 最终优化版本 (`pdf_to_md_final.py`)
- 集成高级图片质量检测
- 在提取过程中实时过滤低质量图片
- 详细的质量报告和统计信息

## 质量检测标准

### 过滤条件
1. **尺寸过滤**: 宽度或高度小于50像素
2. **黑色比例**: 超过95%的像素为黑色（亮度<20）
3. **平均亮度**: 平均亮度低于5
4. **亮度变化**: 标准差小于2（过于单一）
5. **亮度范围**: 最大最小亮度差小于10
6. **颜色多样性**: 唯一颜色值少于5种

### 质量评估指标
- **亮度统计**: 平均值、标准差、最小值、最大值
- **黑色比例**: 黑色像素占总像素的百分比
- **颜色多样性**: 图片中不同颜色的数量

## 使用方法

### 方法1: 使用最终优化版本（推荐）
```bash
python pdf_to_md_final.py
```

### 方法2: 分步处理
```bash
# 1. 基础转换
python pdf_to_md_with_images.py

# 2. 清理低质量图片
python clean_images.py
```

通过实施多层次的图片质量检测机制，成功解决了PDF转换过程中的全黑图片问题，显著提升了输出质量。最终版本能够：
