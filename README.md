# 昆泰芯片产品目录网站

## 项目概述

这是基于昆泰芯片产品目录生成的Markdown格式网站，包含了公司所有产品系列的详细信息。每个产品型号都有独立的页面，包含产品介绍、核心参数和相关文档链接。

## 产品系列分类

### 🧲 霍尔传感器系列
- **3D霍尔传感器 (57系列)**: 三维霍尔传感器，适用于手表、汽车、消费电子等应用
- **线性霍尔传感器 (3XXX系列)**: 线性霍尔传感器，提供模拟输出

### 🎯 磁编码器系列
- **高分辨率磁编码器 (58/59系列)**: 高分辨率角度编码器
  - KTM58系列: XMR磁阻技术，30bit分辨率
  - KTM59系列: TMR技术，24bit绝对角度
- **磁编码角度传感器 (74/78系列)**: 高速磁编码角度传感器

### 🔘 开关传感器系列
- **1D霍尔开关 (136系列)**: 单轴霍尔开关
- **2D霍尔开关 (462系列)**: 双轴霍尔开关
- **3D霍尔开关 (460系列)**: 三轴霍尔开关
- **通用霍尔开关 (15/16/17系列)**: 通用霍尔开关
- **TMR开关 (13/19系列)**: 隧道磁阻开关
- **高压霍尔开关 (25/26系列)**: 高压应用霍尔开关
- **线性霍尔传感器 (56系列)**: 线性霍尔传感器

### 🌡️ 其他传感器系列
- **AMR气缸开关 (28系列)**: 各向异性磁阻气缸传感器
- **运算放大器 (X33系列)**: 运算放大器
- **漏电流检测ASIC (X1系列)**: 漏电流检测专用芯片
- **温度传感器 (112系列)**: 高精度温度传感器

## 页面内容结构

每个产品页面包含以下标准内容:

1. **产品概述**: 产品的基本介绍和主要特点
2. **核心特性**: 关键技术参数和性能指标
3. **主要应用**: 典型应用场景和行业
4. **技术规格**: 详细的电气特性和性能参数表格
5. **引脚定义**: 封装和引脚功能说明
6. **应用电路**: 典型应用电路图和设计指导
7. **设计注意事项**: 重要的设计考虑和建议
8. **封装信息**: 物理尺寸和封装规格
9. **订购信息**: 产品型号和包装方式
10. **相关文档**: 链接到PDF数据手册和应用资料

## 文档链接说明

所有产品页面都包含指向原始PDF文档的链接，这些文档位于相应的产品目录文件夹中:

- **产品手册**: 中文版详细产品手册
- **数据手册**: 英文版技术规格书
- **应用指南**: 应用电路和设计指导
- **评估板资料**: 开发板和评估工具

## 使用方法

### 浏览产品
1. 从 `Home.md` 主页开始浏览
2. 点击产品系列链接查看产品列表
3. 点击具体产品型号查看详细信息
4. 使用侧边栏快速导航到其他产品
5. 使用navigation.md查看完整产品导航

### 查找产品
- 按应用领域查找: 汽车、工业、消费电子等
- 按技术类型查找: 霍尔、TMR、XMR
- 按封装类型查找: SOT-23、QFN、SIP等

### 获取技术支持
每个产品页面都包含技术支持联系方式，可以获得:
- 产品选型建议
- 应用电路设计
- 样品申请
- 技术培训

## 网站部署

### 静态网站生成
可以使用以下工具将Markdown文件转换为HTML网站:

1. **Jekyll**: GitHub Pages原生支持
2. **Hugo**: 快速静态网站生成器
3. **GitBook**: 文档专用平台
4. **Docsify**: 无需构建的文档网站

### 推荐配置 (Jekyll)
创建 `_config.yml` 文件:

```yaml
title: 昆泰芯片产品目录
description: 专业传感器芯片制造商
baseurl: "/product-catalog"
url: "https://your-domain.com"
markdown: kramdown
highlighter: rouge
theme: minima
plugins:
  - jekyll-feed
  - jekyll-sitemap
```

### 本地预览
```bash
# 安装Jekyll
gem install jekyll bundler

# 在网站目录运行
jekyll serve

# 访问 http://localhost:4000
```

## 维护更新

### 添加新产品
1. 在根目录下创建新的产品页面 (KTHxxxx.md)
2. 按照现有模板填写产品信息
3. 在Home.md主页中添加新产品链接
4. 在navigation.md导航页面中添加产品链接
5. 在_Sidebar.md侧边栏中添加快速访问链接

### 更新产品信息
1. 直接编辑对应的Markdown文件
2. 更新技术规格表格
3. 添加新的应用案例
4. 更新相关文档链接

### 版本控制
建议使用Git进行版本控制:

```bash
git add .
git commit -m "更新产品信息"
git push origin main
```
